# Changelog

Все заметные изменения по версиям. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-08

Версия про то, чтобы переезд на новый сервис занимал минуту, а не вечер.

### Добавлено

* **Перезапуск браузера прямо из программы.** Браузер держит собственный DNS-кэш и пул
  открытых соединений в памяти, поэтому после смены адресов продолжает ходить по старым
  и `ipconfig /flushdns` этого не лечит. На телефоне ту же работу делает режим полёта.
  Теперь у программы есть галочка «Перезапускать браузер после «Применить»» (включена
  по умолчанию) и отдельная команда `--restart-browser`. Закрываются Chrome, Edge, Firefox,
  Opera, Яндекс, Brave, Vivaldi — сначала вежливо (`CloseMainWindow`), через 5 секунд
  принудительно, потом запускаются заново.
* **Кнопка «Починить Gemini»** и команда `--fix-gemini`: убирает домены Gemini из `hosts`,
  сбрасывает кэш DNS, перезапускает браузер и открывает `gemini.google.com` — одно нажатие
  вместо ручной последовательности.
* Команда `--browsers` — какие браузеры сейчас запущены.

* **Галочки по сервисам.** Раньше список доменов был жёстко зашит и включался целиком.
  Теперь в окне список из восьми сервисов, каждый можно включить или выключить отдельно,
  а выбор запоминается в `selected.txt` рядом с exe. По умолчанию включено всё.
* **Grok (xAI)** — `grok.com`, `assets.grok.com`, `accounts.x.ai`. Проверено: напрямую 403,
  через прокси 200.
* **TikTok (веб)**, **Instagram**, **X / Twitter**, **Telegram** — в списке с честными пометками:
  у Instagram домены есть в списке сервиса, но сейчас прокси их не обслуживает; X и Telegram
  сервис не обслуживает вовсе (замеры в `docs/commonnet.md`).
* **Поиск адреса по ссылке.** Поле «Ссылка на сервис» и кнопка «Найти адрес»: программа качает
  страницу или файл hosts, разбирает ответ DoH, сама догадывается до raw-файлов GitHub-репозитория
  и, если дано DNS-имя, спрашивает этот сервер напрямую. Каждый найденный адрес проверяется
  запросом к `chatgpt.com`, и в поле подставляется только тот, который реально пускает.
* Консольные команды `--services`, `--version`, `--help`; у `--apply` появился необязательный
  фильтр по сервисам: `--apply 217.60.179.6 Grok,TikTok`.
* `build.ps1` с ключами `-Cli` и `-Clean`, `build.cmd` для сборки двойным кликом.

### Изменено

* **Новый интерфейс.** Тёмная шапка, карточки, скруглённые кнопки с подсветкой, статус
  включённого обхода отдельной строкой. Скриншот — `screenshots/app.png`.
* Код разнесён по файлам (`Services`, `Core`, `Gui`, `Program`, `AssemblyInfo`) вместо одного
  на 47 КБ: так репозиторий читается.
* Сборка больше не требует запоминать команду — `build.cmd`.

### Исправлено

* **Gemini ломался при включении через прокси.** Прокси отдаёт только саму страницу,
  а бэкенды приложения и `accounts.google.com` идут напрямую из РФ — Google видел разные
  регионы и отвечал «не удалось обработать запрос». Теперь у Gemini отдельный статус
  `DoNotEnable`: в списке он помечен «НЕ включать, ломает вход», по умолчанию не отмечен,
  `--apply` без фильтра его не берёт, а при ручном включении программа предупреждает в журнале.
* **Домены копились в `hosts` при каждом «Применить».** Состояние «внутри блока» хранилось
  в переменной, где `0` означало одновременно «не внутри блока» и «внутри блока номер 0» —
  а свой маркер как раз первый в списке. Свой блок не вырезался, строки добавлялись поверх:
  ждали 3 домена, получали 29. Теперь «не внутри» — это `-1`.
* **Осиротевший `# ai-bypass END` не вычищался** и накапливался (в файле оказывались один
  `BEGIN` и два `END`). Теперь закрывающий маркер без открывающего выбрасывается.
* Java-подобное: кнопки рисовались с белыми квадратами по краям скруглений — стандартная
  отрисовка `Button` проступала из-под своей. Теперь сначала заливается фон, потом форма.
* Русский вывод из PowerShell приходил в консоль кашей — дочерний процесс теперь сам ставит UTF-8.

## [1.0.0] — 2026-11-08

Первая публичная версия.

* Оконная программа и консольные режимы: `--state`, `--check`, `--apply`, `--off`, `--find`,
  `--nrpt-set`, `--nrpt-off`.
* Два способа обхода: подмена адресов в `hosts` и правила разрешения имён (NRPT).
* Резервная копия `hosts` перед каждой правкой, хранятся последние 10.
* Проверка адреса настоящим TLS-запросом с именем сайта в SNI.
* Перед публикацией ужесточена безопасность: `HttpGet` проверяет сертификат по-настоящему
  (раньше принимал любой), а подмена сертификата при проверке адреса показывается в логе.
